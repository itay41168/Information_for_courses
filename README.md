
# 📚 Course Selection Web App

This project was developed as part of a Web Development course during my Bachelor's degree studies.  
It aims to provide an interactive platform for students to search, explore, and register for academic courses in an intuitive way.

## 💡 Project Features

The application includes the following key features:

- 🔍 **Advanced Course Search**  
  Search for courses by **year**, **semester**, **subject**, and **lecturer**.

- 📄 **Detailed Course Information**  
  View each course's **basic info** and **syllabus** to better understand the content.

- 📝 **Course Registration**  
  Register for courses directly through the platform.

- ⭐ **Student Reviews**  
  Share and read **student feedback** on courses. This helps build a community-based insight system based on past student experiences.

- 📆 **College Calendar View**  
  Access the official academic **calendar** to stay updated with events and important dates.

## 🛠️ Technologies Used

- HTML, CSS, JavaScript  

## 🧭 How It Works

The system allows students to interact with course data, select courses without scheduling conflicts, and benefit from a social layer by reading peer reviews.

### Example Use Case:
1. A student searches for second-year computer science courses.
2. They view detailed information about each course, including syllabus and professor.
3. After reading student reviews, they register for selected courses.
4. They check the semester calendar to avoid overlaps with personal plans.
